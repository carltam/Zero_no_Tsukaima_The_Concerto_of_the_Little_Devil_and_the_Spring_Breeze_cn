# 读档标题乱码修复说明（fix_save_titles.py）

## 现象

PCSX2 读档界面里，每条存档的章节标题是乱码汉字，例如：

```
涼懐来給              女人的検              真正的心隙              肩補鎖塔怯胃的危撮
```

## 根因（已完整定位）

1. 章节标题由剧本里的 `title("...")` 设置，存盘时主程序（`0x1184d8`，
   纯 `strncpy`）把标题码**原样**拷进记忆卡，不做任何码制转换；
2. 读档时游戏用**同一套 NORMAL.BIN 字库 + 合并码表**渲染这些码；
3. 出问题的 4 个存档是**开发过程早期构建**写入的，用的是当时的码位分配。
   早期码位与最终版已有出入——最典型：旧码 `8CA8` = 「託」，最终版
   `8CA8` = 「肩」。于是旧存档渲染出来就是乱码；
4. **最终版 ROM 对新存档写的标题是正确的**（剧本 title() 字节无误 +
   存盘原样拷贝 + 读档同码表渲染，链路自洽）。所以乱码只影响旧存档。

每条存档的章节是用存档里的**进度标记**（标题字段前的一个单调递增整数）
反推确认的：两条已知存档标定场景速率 ≈342–349/场景，推得另两条的场景号。

## 修复

工具 `fix_save_titles.py` 按**最终码表**重写记忆卡里的标题字段：

```bat
:: 1) 先扫描（只读，报告所有存档标题与解码情况）
python fix_save_titles.py --scan

:: 2) 修复（写前自动备份，写后自动校验，可重复运行）
python fix_save_titles.py
```

内置修复表（适用于随项目附带的那张记忆卡 `Mcd001.ps2`）：

| 存档 | 偏移 | 修前（乱码） | 修后（正确） | 章节 |
|---|---|---|---|---|
| save01 | 0x2211494 | 涼懐来給 | 黑发来客 | 00068 |
| save02 | 0x2224e14 | 女人的検 | 女人的战斗 | 00137 |
| save03 | 0x2227b74 | 真正的心隙 | 真正的心意 | 00269 |
| save04 | 0x22262b4 | 肩補…危撮 | 託裏斯塔尼亚的危机 | 00219 |

换了一张记忆卡，或存档位置不同时：

```bat
python fix_save_titles.py --scan                          :: 拿到新的偏移量
python fix_save_titles.py --fix 0x2211494:黑发来客        :: 逐条指定（可多次）
python fix_save_titles.py --mcd D:\emu\Mcd001.ps2         :: 指定记忆卡路径
```

工具行为：

- **写前备份**：`Mcd001.ps2.bak_titlefix_<时间戳>`（`--no-backup` 可关，不推荐）；
- **写后校验**：重新读盘解码，与目标标题不一致即报错并提示用备份还原；
- **幂等**：已经是正确标题的存档自动跳过；
- 只改标题缓冲区（每档 100 字节字段内的若干字节），不动目录项——PS2 记忆卡
  文件数据本身没有校验和，不会因改内容而加载失败。

## 修复后生效方法

在 PCSX2 里**退出到 PS2 浏览器或重启一次模拟器**（让记忆卡重新加载），
再进读档界面即可看到正确标题。

## 不想修旧档？

直接用最终版 ROM 重新通关存新档即可——新档标题本来就是对的。
本工具只是为「舍不得进度」准备的兜底。
