# assets\ — 汉化图片素材

界面里**烘焙进贴图的文字**（游戏不用字库渲染、而是画在图片里的部分）的中文素材。
共 33 个 TM2 贴图，覆盖三类：**菜单**、**人名**、**人物信息**，外加场景横幅与
胜负提示。构建时由 `build_all.ps1` 第 7 步原样打进 NORMAL.BIN
（日志对应 `ui textures: 33 entries`）。

## 目录

| 路径 | 说明 |
|---|---|
| `menu_images\*.tm2` | 33 个中文贴图，**构建直接消费**；同名覆盖即完成替换 |
| `preview\*.png` | 14 张效果预览图（人工核对用，不参与构建） |
| `textures_manifest.csv` | NORMAL.BIN 全部 360 个图片条目清单（编号/尺寸/位深/汉化状态） |

## 33 个条目分类

| 分类 | 条目号 | 内容 |
|---|---|---|
| 主界面 UI | 00011 | 综合图集：AUTO PLAY、UP/DOWN、HP/MP、演奏开始/返回、持有数 MIN/MAX、好感度条（露易丝的撒娇度 / 对才人的感情）、战斗参加者 |
| 菜单·选项 | 00012 | 系统与选项文本图集：角色名表（露易丝/才人/谢斯塔/基修/塔巴萨/丘鲁克/安丽埃塔/蒙莫朗西/奥斯曼/科尔贝尔/德弗林格/蒂法妮娅…）、菜单项（音效、消息速度、自动速度、跳过、震动功能、语音设置、恢复默认设置、读取游戏、新游戏、选项、影像模式、音乐模式、场景选择、配音演员、道具、角色、保存、读取、返回标题、战斗开始、进入下一章、声音、BGM、语音、咖啡时间、指令、战斗准备、情报…）、确认框（进入下一章，可以吗？/ 返回标题画面，可以吗？/ 开始战斗吗？） |

> 条目号即 NORMAL.BIN 里的图片索引；`textures_manifest.csv` 里有每个条目的
> 尺寸与位深，替换贴图时必须保持一致。

## 如何更新一张图

1. 取得同名 TM2（可从原版 ISO 的 NORMAL.BIN 用通用 TIM2 工具导出）；
2. 用 PS2 TIM2 编辑器改图——**保持尺寸、位深、调色板结构不变**，
   只替换文字像素；
3. 覆盖 `menu_images\` 下同名文件；
4. 重跑 `一键打包.bat`，确认日志出现 `ui textures: 33 entries`。

改图工具不在本仓库范围内（需要 TIM2 编辑器）；本仓库负责把改好的图
**正确打进 ROM**——构建只认「文件名 = 条目号」，不校验图片内容。
