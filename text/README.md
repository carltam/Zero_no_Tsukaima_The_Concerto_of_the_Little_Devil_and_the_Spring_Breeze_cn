# text\ — 日文原文 + 中文译文

本目录是汉化的**文本源**：每个文件都是「日文原文 + 中文译文」对照表，
构建时由 `tools\text_inject.ps1` 注入游戏。改译文只改本目录，然后重跑
`一键打包.bat`。

## 文件清单

| 文件 | 格式 | 用途 |
|---|---|---|
| `00005.tsv` … `01853.tsv` | 三列 TSV | 1,765 个场景的剧本（对白/旁白/章节标题） |
| `system_map.tsv` | 两列 TSV | 系统文本：菜单、提示、确认框 |
| `speakers.tsv` | 两列 TSV | 人物名：写进对话名牌，并做全局串替换 |
| `battle_text.tsv` | 两列 TSV | 战斗文本：技能/道具名与说明、角色简介（定长表） |
| `elf_songs.tsv` | 三列 TSV | 音乐模式 30 首曲名 |

## 格式细则

### 场景剧本（三列）

```
编号 <TAB> 日文原文 <TAB> 中文译文
0	どこで爆発だ！	爆炸在哪！
1	は、大通りに面した通りで数回、\n爆薬による爆発が確認されています。	是，面向大道的街上数次，\n已确认炸药爆炸。
```

- 第一列是**编号**，与剧本里 `talk()` 调用的顺序一一对应，**不要增删行**；
- 第二列日文仅用于校对，改动不影响构建；
- 换行写成两个字面量 `\n`（反斜杠 + 字母 n），不是真实换行；
- 文件为 UTF-8 无 BOM；用 Visual Studio Code / Notepad++ 编辑，
  编码选 UTF-8。

### 系统文本 / 人名 / 战斗文本（两列）

```
日文 <TAB> 中文
ルイズ	露易丝
サイト	才人
```

- 按**精确字符串匹配**替换（长的优先）；
- `battle_text.tsv` 是定长字节表：中文编码后字节数 ≤ 日文原文字节数，
  超长构建报 `battle overflow`，需改短；
- 人名同时参与剧本全局替换，改这里对全文生效。

### 音乐模式曲名（三列）

```
编号 <TAB> 日文 <TAB> 中文
```

每个曲名槽位 0x80 字节，中文编码后放得下（构建日志 `patched 30/30 titles`）。

## 修改流程

1. 编辑对应 TSV（只改中文列）；
2. 重跑 `一键打包.bat`；
3. 码表自动按新译文重算——**新增的字会自动安排槽位，无需维护编码表**；
4. 若报 `charset exceeds capacity`：译文引入了过多新字，按日志提示
   替换低频字（改用已有同义字）或删减未使用译文。

## 注意事项

- 译文中的引号 `"` 与反斜杠 `\` 会被自动转义，可直接使用；
- 章节标题也在场景剧本里（`title("章节名")`），随对白一起注入；
- 不要删除任何 TSV 文件——构建按文件名清单处理，缺文件会少注入内容。
